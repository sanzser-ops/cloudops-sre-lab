# CloudOps & SRE Engineering Lab

Hands-on lab for learning and demonstrating CloudOps, DevOps and Site Reliability Engineering practices.

## Technologies

- AWS
- Terraform
- Ansible
- Jenkins
- Python
- Podman
- Prometheus
- Grafana
- Linux (RHEL and Ubuntu)

## Objectives

- Infrastructure as Code
- CI/CD automation
- Configuration management
- Monitoring and alerting
- Incident response and troubleshooting
- Reliability engineering

## Cost Policy

The lab aims to maintain a zero-cost operating model.
Local virtual machines and free, open-source tools are preferred.
No AWS infrastructure will be deployed without reviewing its potential costs first.

## Repository Structure

- `terraform/`: Infrastructure as Code
- `ansible/`: Configuration management
- `python/`: Automation scripts
- `jenkins/`: CI/CD pipeline definitions
- `monitoring/`: Prometheus and Grafana configuration
- `docs/`: Architecture and operational documentation
