# CloudOps & SRE Engineering Lab

Hands-on lab for learning and demonstrating CloudOps, DevOps and Site Reliability Engineering practices.

## Technologies

- AWS
- Terraform
- Ansible
- Jenkins
- Python
- Podman
- Prometheus
- Grafana
- Linux (RHEL and Ubuntu)

## Objectives

- Infrastructure as Code
- CI/CD automation
- Configuration management
- Monitoring and alerting
- Incident response and troubleshooting
- Reliability engineering

## Cost policy

The lab aims to minimize costs and avoid unnecessary AWS charges.
Local tools and virtual machines are preferred whenever practical.
No AWS infrastructure is deployed without reviewing its potential costs first.

## Repository structure

- `terraform/`: Infrastructure as Code
- `ansible/`: Configuration management
- `python/`: Automation scripts
- `jenkins/`: CI/CD pipeline definitions
- `monitoring/`: Prometheus and Grafana configuration
- `docs/`: Architecture and operational documentation
